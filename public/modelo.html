Este site também é um modelo

O repositório lgpd-jatoba foi desenhado para ser copiado. Ele entrega uma página de transparência completa em HTML e CSS puros, sem build, sem dependências e sem rastreamento — o tipo de base que dá para publicar em cinco minutos e revisar em uma tarde.

Modelo não é parecer jurídico

Copiar este repositório não torna ninguém conforme à LGPD. O texto é um ponto de partida baseado em boas práticas e em artigos da lei, mas cada operação tem finalidades, bases legais e riscos próprios. Substitua os dados entre colchetes, remova o que não se aplica e revise com quem entende do seu caso.

Como usar

  1. Copie o repositório ou use o botão “Use this template” no GitHub. Não faça fork se quiser um histórico limpo.
  2. Escolha o ponto de partida: template/index.html para uma página só, ou public/ para o conjunto completo.
  3. Substitua os marcadores. Todos seguem o formato [NOME] e aparecem no HTML e no README do template.
  4. Remova seções que não se aplicam. Se você não usa IA, apague a seção de IA. Se não transfere dados, apague a seção de transferência internacional. Texto genérico que não corresponde à realidade é pior do que ausência de texto.
  5. Ajuste prazos e fornecedores. Retenção, suboperadores e bases legais precisam refletir a sua operação, não a do Jatobá Lab.
  6. Revise os cabeçalhos. Se você adicionar JavaScript ou estilos inline, precisará ajustar a CSP em _headers — e talvez repensar a decisão.
  7. Publique. Qualquer host estático serve: Cloudflare Pages, GitHub Pages, Netlify, S3. Em Cloudflare Pages, basta apontar para a pasta public/.
  8. Revise com um profissional antes de usar comercialmente, contratar equipe ou tratar dados sensíveis.

Checklist antes de publicar

  • Todos os marcadores [ ] foram substituídos?
  • O controlador e o DPO existem e têm canal monitorado?
  • As bases legais correspondem ao que o produto realmente faz?
  • Os prazos de retenção são executáveis — existe rotina de expurgo?
  • A lista de fornecedores está atualizada e inclui todos os que veem dados?
  • A seção de transferência internacional reflete os países reais?
  • Se há IA: prompts, memória, logs e retenção estão descritos com precisão?
  • Os termos têm foro e limitação de responsabilidade adequados ao seu caso?
  • A CSP em _headers funciona com o site (sem bloquear CSS ou imagens)?
  • security.txt tem e-mail válido e data de expiração futura?
  • O site passa em navegação por teclado e leitor de tela?
  • Alguém com conhecimento jurídico revisou o conjunto?

Starter de uma página

Se você precisa de algo menor, o arquivo template/index.html traz uma página única com as seções essenciais e um banner de “Modelo — adapte e revise antes de publicar”. O template/README.md tem o checklist correspondente.

Sugestão de fluxo

Comece pelo template de uma página para validar o conteúdo com o time. Só depois expanda para o conjunto completo de public/. É mais fácil revisar texto curto do que reescrever cinco páginas.
